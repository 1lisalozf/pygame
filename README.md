# Vertical Shooter (S/W engineering proj 1)

화면 아래쪽 플레이어 비행기를 좌우로 움직이며 총알을 쏘아, 위에서 내려오는 적을 맞히는 종스크롤 슈팅 게임.

## 실행 방법
1. 프로젝트 폴더에서 터미널 실행
2. python -m pip install pygame==2.6.1으로 Pygame 설치
3. python main.py로 게임 실행

## 조작

| 키 | 동작 |
|---|---|
| ← / → | 좌우 이동 |
| Space | 시작 화면에서 게임 시작 / 게임 중 총알 발사 |
| R | 게임 오버 후 다시 시작 |
| Esc | 종료 (시작 화면에서도) |

## 파일 구성

| 파일 | 내용 |
|---|---|
| `main.py` | 게임 루프 — 입력 처리, 갱신, 그리기, 점수·생명·게임 오버 |
| `entities.py` | 그림 불러오기(`load_frame`), 배경(`Background`), 스프라이트 클래스 — `Player`, `Bullet`, `Enemy` |
| `settings.py` | 화면 크기·속도·색 같은 상수 |
| `assets/` | 그림 — ansimuz CC0 픽셀 아트 (출처: `assets/CREDITS.md`) |
| `AI_USAGE.md` | 생성형 AI 사용 기록 |

## 구현한 기능

- [x] F1 플레이어 이동 - 방향키 이용한 좌우이동 및 화면 경계 구현
- [x] F2 총알 발사 - SPACE키로 총알을 발사하고, 화면 밖의 총알을 제거하도록 구현
- [x] F3 적 명중과 점수 - 총알과 적의 충돌을 판정하고 적을 없앨 시 점수를 10점씩 추가하도록 구현
- [x] F4 피격과 게임 오버 - 적과 충돌하는 경우와 적을 놓치고 화면 아래부분에 닿았을 때 생명이 감소, 생명이 0일 경우 게임 오버 처리
- [x] F5 재시작과 최고 점수 - R키를 누르면 재시작 및 최고 점수를 저장하고 이를 불러오는 기능 구현

## 게임 규칙
- 게임 시작 시 생명은 3개입니다.
- 적을 한 마리 처치할 때마다 10점을 획득합니다.
- 적과 충돌하거나 적을 놓치면 생명이 감소합니다.
- 생명이 0 이하가 되면 게임이 종료됩니다.
- 최고 점수는 파일에 저장되며 게임을 다시 실행해도 유지됩니다.
